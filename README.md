# Hand Gesture Recognition

The project requires a specific version of Python and the compatible version of its libraries.

### Python Version
- Python 3.11
- Install every other library using: pip install -r requirements.txt

Setting up a virtual environment is recommended.
- python3.11 -m venv venv

The data has not been uploaded here. To train the model using your own data, use https://teachablemachine.withgoogle.com/
The new label names must be added to label in test.py
